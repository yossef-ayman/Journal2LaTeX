# PDF Analyzer (Academic Reference Explorer)

مشروع متكامل ومفصول بدقة بين الواجهة الأمامية (Frontend) والواجهة الخلفية (Backend) لتحليل ملفات PDF العلمية واستخراج المراجع وإثرائها عبر محركات أكاديمية متعددة (OpenAlex, Google Scholar, Crossref).

---

## 📂 هيكل المشروع (Project Structure)

```
pdf_analyzer/
│
├── frontend/                     # مجلد الواجهة الأمامية (مستقل بالكامل)
│   ├── index.html                # واجهة المستخدم الرئيسية
│   ├── css/
│   │   └── style.css             # التصاميم والألوان ودعم الوضع الليلي/النهاري
│   ├── js/
│   │   ├── config.js             # إعدادات الـ API والاتصال بالسيرفر
│   │   └── script.js             # منطق التفاعل وتحديث الواجهة
│   └── README.md                 # دليل استخدام وتعديل الفرونت إند
│
├── backend/                      # مجلد الواجهة الخلفية (FastAPI Backend)
│   ├── main.py                   # السيرفر ونقاط الـ API ودعم CORS
│   ├── run.py                    # سكربت تشغيل الباك إند
│   ├── requirements.txt          # الحزم المطلوبة
│   ├── enrichment/               # محركات التحليل والمطابقة والبحث
│   ├── data/                     # التخزين المؤقت والمشاريع المستخرجة
│   ├── tests/                    # اختبارات النظام
│   └── README.md                 # دليل الباك إند
│
├── run.py                        # سكربت تشغيل سريع من المجلد الرئيسي
└── README.md                     # هذا الملف
```

---

## 🚀 التشغيل السريع

### تشغيل الباك إند:
```bash
python run.py
```
أو من داخل مجلد الباك إند:
```bash
cd backend
python run.py
```

### فتح وتعديل الفرونت إند:
- يمكنك فتح مجلد `frontend` في أي محرر وتعديل ملفات الـ HTML/CSS/JS بحرية.
- يمكنك تشغيل الواجهة عبر **Live Server** في VS Code أو فتح `frontend/index.html` في المتصفح، وستتصل تلقائياً بالباك إند.
- كما يمكن فتح التطبيق مباشرة عبر الرابط [http://127.0.0.1:8080](http://127.0.0.1:8080) عند تشغيل السيرفر.
