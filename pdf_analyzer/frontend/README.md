# PDF Analyzer - Frontend

مجلد الواجهة الأمامية المستقل لمحلل ومستكشف الأوراق العلمية (PDF Analyzer).

---

## 📁 هيكل المجلد

```
frontend/
├── index.html         # الصفحة الرئيسية للتطبيق
├── css/
│   └── style.css      # ملف التنسيقات والتصميم الكامل مع دعم Light / Dark Mode
├── js/
│   ├── config.js      # إعدادات عنوان سيرفر الـ API (API_BASE_URL)
│   └── script.js      # منطق الواجهة وإرسال الطلبات وعرض البيانات التفاعلية
└── README.md          # هذا الدليل
```

---

## 🚀 كيفية تشغيل وتعديل الفرونت إند

### 1. التشغيل المستقل (Standalone) باستخدام Live Server أو المتصفح
- يمكنك فتح مجلد `frontend` في محرر الأكواد (مثل VS Code) وتشغيل إضافة **Live Server**.
- أو فتح `index.html` مباشرة في المتصفح.
- عند التشغيل المستقل، سيتصل الفرونت إند تلقائياً بالباك إند على العنوان `http://127.0.0.1:8080` بفضل الإعدادات في `js/config.js`.

### 2. تغيير عنوان الباك إند
إذا كان الباك إند يعمل على بورت أو خادم مختلف، يمكنك تعديل متغير `window.API_BASE_URL` في ملف `js/config.js`:
```javascript
window.API_BASE_URL = 'http://127.0.0.1:8080';
```

### 3. التعديل على التصميم والستايل
- لتعديل الألوان والخطوط والمؤثرات، افتح ملف `css/style.css`.
- يحتوي الملف على متغيرات CSS للمظهرين الفاتح والداكن في أعلى الملف (`:root` و `[data-theme="dark"]`).
